Website Architecture, Codebase, Editing & Deployment Manual

Author: Website Engineering Team  |  Stack: Next.js 14, React 18, TypeScript, Tailwind CSS  |  Published: September 2026

1. Website Overview & Core Architecture

This website is a modern, responsive web application engineered specifically for CSI Christ Church Kallidaikurichi. It provides church information, service schedule management, online sermon streaming, ministry highlights, photo gallery with lightbox, prayer request dispatching, and branch churches (sub-churches) directory.

⚡ Core Technologies
  • Framework: Next.js 14.2 (App Router architecture)
  • Language: TypeScript 5.5 (Strict type checking)
  • Styling: Tailwind CSS 3.4 (Custom church colors)
  • Icons: Lucide React (featherweight SVG icons)
  • Fonts: Google Noto Sans Tamil & Inter
🌐 Key Website Features
  • Two-Tier Header: Main header + high-contrast sub-header
  • Adaptive Worship Scheduler: 1st–5th Sunday dynamic detection
  • YouTube Integration: Latest, Live Stream, and Popular videos
  • Photo Gallery: 21 optimized photos with interactive lightbox
  • Prayer Request: Auto-email to official inbox + WhatsApp fallback

2. The Central Control Panel: data/church.ts

To ensure non-programmers can easily update this website, 90% of all website content is centralized in a single file:
d: or website amil-church-website amil-church\data\church.ts

💡 Golden Rule of Editing:
When you need to change phone numbers, email, WhatsApp, pastor details, service timings, sermon videos, sub-churches, or gallery photos, you only need to edit data/church.ts! You do not need to touch HTML or complex React code.

⚠️ Critical Note Regarding Apple iPhone HEIC & Camera DNG Files:
Web browsers (Google Chrome, Safari on Windows/Android, Edge, Firefox) cannot display .HEIC or .DNG files natively. Always convert images to .jpg or .png before putting them into public/images/. All 6 original HEIC photos and DNG photos from your Used folder have already been pre-converted and optimized into public/images/gallery/.

4. Step-by-Step Guide: How to Edit Content

A. Updating Pastor or Catechist Details

  1. To replace the Chief Pastor's photo: Copy your new photo to public/images/chief-pastor.png (overwriting the file).
  2. To replace the Catechist's photo: Copy your new photo to public/images/catechist.png.
  3. Open data/church.ts and update the text: 
    pastorName: "Rev. P. Muthuraj M.Sc., B.D., P. G.Dip. Th.",
pastorTitle: "தலைமை போதகர் (Chief Pastor & Pastorate Chairman)",
catechistName: "திரு. T. ரெபின் ஆஸ்டின் B.A., B.D.",
catechistTitle: "சபை ஊழியர் (Catechist)",

B. Updating Sunday Worship Schedule & Oraman Times

The worship schedule logic in components/ServiceTimes.tsx automatically determines the current week of the month (1st through 5th week):

  • 1st Sunday: திருவிருந்து ஆராதனை (Holy Communion Service) — 09:00 to 11:30 AM
  • 2nd Sunday: வழக்கமான ஆராதனை (Regular Service) — 09:00 to 11:30 AM
  • 3rd Sunday: திருவிருந்து ஆராதனை (ஆங்கிலிக்கன் முறைமை - Anglican Order) — 09:00 to 11:30 AM
  • 4th Sunday: ஆராதனை (Worship Service) + 4வது வார உபவாச ஜெபம் (Fasting Prayer)
  • 5th Sunday (when present): வழக்கமான ஆராதனை (Regular Service) — 09:00 to 11:30 AM
  • Every Tuesday: சுகமளிக்கும் ஆராதனை (Healing Service) — 07:00 to 08:00 PM
  • Every Friday: வேதாகம ஆராய்ச்சி (Bible Study) — 07:00 to 08:00 PM

6. Publishing Live to the World (Vercel & GitHub)

To make your website available to anyone in the world 24/7 without needing your personal computer to stay on:

Step 1: Push Code to GitHub (Backup & Version Control)

# 1. Create a free repository on https://github.com named "csi-christ-church-website"
# 2. In your terminal, link and push your code:
git remote add origin https://github.com/YOUR_USERNAME/csi-christ-church-website.git
git push -u origin main

Step 2: Deploy to Vercel (100% Free Hosting with HTTPS)

  1. Create a free account at vercel.com using your GitHub account.
  2. Click "Add New..." → "Project".
  3. Select your csi-christ-church-website repository and click "Import".
  4. Click "Deploy" without modifying any settings.
  5. Within 60 seconds, your site is live worldwide at: https://csi-christ-church-website.vercel.app!

Step 3: Continuous Automatic Deployment (CI/CD)

Whenever you make updates in the future (e.g., adding a new gallery photo or changing sermon links): 

# Stage all changed files:
git add .

# Save with a message:
git commit -m "Updated sermon video and service announcements"

# Push to GitHub:
git push

Vercel automatically detects the push and re-deploys your live website in under 60 seconds!

🌐 Adding a Custom Domain (e.g., csichristchurchkallidai.org):
In your Vercel Dashboard → Go to Settings → Domains → Enter your domain name and point the DNS records (A Record: 76.76.21.21 or CNAME: cname.vercel-dns.com). Vercel provides automatic, free SSL security certificates forever.

7. Troubleshooting & Frequently Asked Questions

Issue Encountered Probable Cause Immediate Solution
Port 3000 already in use Another background Node instance is running. Run Get-Process node | Stop-Process -Force in PowerShell, then re-run npm run dev.
New photo not appearing Filename mismatch or missing from data/church.ts. Check exact casing and extension (e.g. .jpg vs .jpeg) and ensure the file exists in public/images/.
Mobile phone cannot load site Computer IP changed or phone on different Wi-Fi. Check your PC's IP using ipconfig and ensure you ran npm run dev -- -H 0.0.0.0.
Prayer request email inquiry Official recipient address. All prayer submissions are directed to csichristchruchofficial@gmail.com and open pre-filled mail clients.

8. Birthday & Wedding Anniversary Management System

The website features an automated Birthday and Wedding Anniversary greeting system for church families. It displays upcoming events for the next 30 days (Asia/Kolkata timezone), highlights today's celebrations with animated badges, and allows administrators to bulk-import church records from Excel spreadsheets.

Supported Excel Spreadsheets

  • Birthday List (Birthday_List.xlsx): Sheet named Birthdays with columns Name and Date of Birth.
  • Wedding Anniversary List (Anniversary_List.xlsx): Sheet named Anniversaries with columns Husband/Wife Names and Anniversary Date.

Supported Date Formats

  • Native Excel numeric serial dates (e.g., 45292 → 2024-01-01)
  • Standard date strings: DD-MM-YYYY, DD/MM/YYYY, YYYY-MM-DD
  • Leap year handling: February 29th events automatically map to February 28th during non-leap years.

Database Schema (Supabase SQL)

CREATE TABLE IF NOT EXISTS public.church_people_dates (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  date_of_birth DATE,
  anniversary_date DATE,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  created_by UUID REFERENCES auth.users(id) ON DELETE SET NULL
);

-- Indexes for high-performance date lookups & search:
CREATE INDEX idx_church_people_dob ON public.church_people_dates (date_of_birth);
CREATE INDEX idx_church_people_anniversary ON public.church_people_dates (anniversary_date);
CREATE INDEX idx_church_people_name ON public.church_people_dates (name);

-- Row Level Security (RLS):
ALTER TABLE public.church_people_dates ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public read celebration dates" ON public.church_people_dates FOR SELECT USING (true);
CREATE POLICY "Admins full manage church_people_dates" ON public.church_people_dates
  FOR ALL USING (auth.role() = 'authenticated') WITH CHECK (auth.role() = 'authenticated');

Admin Dashboard Operations

  1. Log in to /admin using your church administrator credentials.
  2. Click the 🎂 பிறந்தநாள் & திருமண நாள் மேலாளர் (Birthday & Anniversary Manager) tab.
  3. Select either பிறந்தநாள் (Birthday) or திருமண நாள் (Anniversary).
  4. Choose or drag-and-drop your .xlsx file. The system parses and previews the records.
  5. Click இறக்குமதியை உறுதிசெய் (Confirm & Import). The system merges records by member name and reports imported, updated, and skipped counts.
  6. Use the search bar, manual add button, edit icon, or delete icon to update individual records at any time.
