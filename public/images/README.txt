Put your real photos in this folder using these exact filenames
(the code already references them):

church-logo.png       — your church logo
church-hero.jpg       — big homepage background photo
church-building.jpg   — photo used in the About section
sermon-01.jpg / sermon-02.jpg / sermon-03.jpg — sermon thumbnails
children-ministry.jpg
youth-ministry.jpg
women-ministry.jpg
prayer.jpg
worship.jpg
outreach.jpg
gallery-01.jpg, gallery-02.jpg, gallery-03.jpg, ... — add as many as you like,
  then list them in data/church.ts under `galleryImages`

Recommended: compress photos (e.g. with squoosh.app) to under ~300KB each
before adding them, so the site stays fast.
